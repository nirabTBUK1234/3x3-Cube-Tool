# Security Policy

## Supported Version

The supported version of CubeTool is:

**Version 1**

## Reporting a Security Issue

If you find a security vulnerability or security-related issue in CubeTool, please report it privately rather than publicly posting it.

Please include:

* A description of the issue
* Steps to reproduce it
* Your operating system
* Any relevant error messages

Do not include passwords, personal information, or other sensitive information in your report.

## Security Updates

Security issues will be reviewed and addressed when possible.

Users should use the latest release of **Version 1**.
